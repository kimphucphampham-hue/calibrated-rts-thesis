This repository supports the reproduction of the previous graduation project and the implementation of pilot experiments for the master's thesis.

## Repository Structure

- `legacy/`: Source code and artifacts from the previous graduation project
- `data/raw/synthetic/`: Synthetic dataset used for legacy reproduction
- `data/raw/tcp_ci/`: TCP-CI raw data, which is not tracked by Git
- `configs/`: Experiment configuration files
- `docs/`: Documentation and data dictionary
- `results/`: Results generated by the experimental pipelines


## Validate the Synthetic Dataset

From the repository root, create and activate a Python virtual environment, then install the required dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-lock.txt
```

Regenerate the synthetic dataset for reproducibility verification:

```bash
python legacy/generate_synthetic_data.py
```

The regenerated dataset is saved at `data/interim/synthetic_regenerated.csv`

The frozen artifact at `data/raw/synthetic/synthetic_data.csv` is not overwritten

Validate the frozen synthetic dataset:

```bash
python src/validate_data.py
```

Run the original protocol:

```bash
python legacy/reproduce_legacy.py --mode original
```

Run the corrected protocol:

```bash
python legacy/reproduce_legacy.py --mode corrected
```

Run both protocols:

```bash
python legacy/reproduce_legacy.py --mode both
```

Run the automated tests:

```bash
python -m pytest -v
```

Reproduction results are saved at `results/legacy/reproduction/`

The `original` mode reproduces the row-level
`TimeSeriesSplit` found in the available legacy source.

The `corrected` mode applies temporal splitting to unique
Sprint identifiers so that one Sprint cannot occur in both
training and testing data.
